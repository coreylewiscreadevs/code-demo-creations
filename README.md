## Explore & Experiment

Whether you're here to learn something new, find inspiration, or bring an interaction into your next project, you're welcome to explore, adapt, and build upon the work.

## Getting Started

**Download a single demo**

If you only need one experiment, you can download its directory without cloning the entire repository using [degit](https://github.com/Rich-Harris/degit).

```bash
npx degit OWNER/REPOSITORY/path-to-demo my-demo
cd my-demo
```

Replace `OWNER/REPOSITORY/path-to-demo` with the GitHub repository and directory path of your chosen demo. This requires Node.js and npm.

**Download the entire collection**

Clone the repository using Git, or select **Code → Download ZIP** at the top of the repository.

```bash
git clone https://github.com/OWNER/REPOSITORY.git
```

Once downloaded, navigate to your chosen demo and follow any setup instructions provided. Some experiments may run directly in your browser, while others may require a local development environment.
